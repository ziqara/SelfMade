# Self-Made: Mindful Time Management & Self-Development

## Суть приложения

**Self-Made** — это комплексная экосистема для осознанного управления временем и личностного роста. Проект создан не просто для трекинга задач, а как умный помощник, который помогает:

* Вести учет ежедневной активности и затраченного времени.
* Отслеживать эмоциональное состояние и уровень настроения.
* Анализировать баланс между работой, отдыхом и саморазвитием.
* Получать персонализированные инсайты, рекомендации и рефлексию на основе искусственного интеллекта (Google Gemini API), который анализирует данные пользователя для достижения его глобальных целей.

## Технологический стек

* **Backend**: C#, .NET Web API, Entity Framework Core (EF Core)
* **Frontend**: React, TypeScript, Zustand
* **База данных**: PostgreSQL 
* **Безопасность**: BCrypt, JWT-based Authentication
* **ИИ-интеграция**: Google Gemini API 
* **Инструменты**: Visual Studio, GitHub, REST API
