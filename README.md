# Self-Made: Mindful Time Management & Self-Development

## 🎯 Суть приложения
**Self-Made** — это комплексная экосистема для осознанного управления временем и личностного роста. Проект создан не просто для трекинга задач, а как умный помощник, который помогает:
- Вести учет ежедневной активности и затраченного времени.
- Отслеживать эмоциональное состояние и уровень настроения.
- Анализировать баланс между работой, отдыхом и саморазвитием.
- Получать персонализированные инсайты, рекомендации и рефлексию на основе **локального искусственного интеллекта (Ollama)**, который изучает привычки пользователя прямо на его компьютере без передачи данных в облако.

## 🛠 Технологический стек
- **Backend**: C#, .NET 10 Web API
- **База данных**: PostgreSQL, Entity Framework Core (EF Core)
- **Фронтенд**: React + TypeScript + Zustand
- **ИИ-интеграция**: Ollama 
- **Инструменты**: Visual Studio, Git / GitHub, REST API (`.http` файлы)
